# Siti Nurzaini Yahya — English ⇄ Malay Translator

Gaming-focused, single-page portfolio for an English ⇄ Malaysian Malay game localizer, with parallax scrolling.

- Pure HTML/CSS/JS — no build step, one file (`index.html`)
- Parallax layers driven by `requestAnimationFrame` (works on mobile, respects `prefers-reduced-motion`)
- Sections: Hero (live string demo) · Market · Character sheet · Services · Malay vs Indonesian · Process · Work · Brief form

## Publish on GitHub Pages
Repo **Settings → Pages → Build and deployment → Deploy from a branch → `main` / root**.
The site will be live at `https://<username>.github.io/<repo-name>/`.
